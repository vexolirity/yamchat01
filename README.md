# NEXUS — Realtime Room Chat

## Jalankan
1. Install Node.js.
2. Ekstrak proyek.
3. Buka terminal di folder proyek.
4. Jalankan `npm install`
5. Jalankan `npm start`
6. Buka `http://localhost:3000`.

Untuk pengujian beberapa perangkat dalam Wi-Fi yang sama, buka `http://IP-KOMPUTER:3000` dari perangkat lain dan gunakan Room ID yang sama.

### Catatan
Pesan disimpan sementara di memory server. Untuk produksi, tambahkan database, autentikasi, HTTPS/WSS, rate limiting, validasi, dan logging.
